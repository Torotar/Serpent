# Documentation assets

This directory contains visual assets used by the user and developer documentation.

- `ui/` contains screenshots copied from repository QA evidence. They show real Serpent surfaces and should be refreshed when the UI changes materially.
- Current user-guide screenshots include `Serpent-Preview.png` (workspace overview), `filter-panel.png` (search/filter entry), `asset-filter.png` (filter dimensions and Shift selection), `AI-config.png` (AI configuration), `AI-analyze-menu.png` (asset AI action menu), `AI-analyze.png` (AI settings/Inspector), `serpent-plugin-community.png` (plugin community), `MCP-settings.png` (MCP setup), and `3D-inspector.png` (model viewer).
- Feature screenshots captured from the Linux build with a synthetic demo library: `collections-inspector`, `tag-management`, `search-syntax`, `automation-script`, `settings-appearance`, `settings-browse`, and `settings-shortcuts`. The `.png` file shows the Chinese UI for the zh docs; the matching `.en.png` shows the English UI for the en docs.
- `diagrams/source/` contains the editable Mermaid sources for the workflow, extension choice, process architecture, and release pipeline diagrams embedded in the Markdown docs.

Screenshots are evidence-oriented and may contain synthetic fixture names or data; they are not product marketing images.
